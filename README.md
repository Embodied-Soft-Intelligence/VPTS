<h2 align="center">An AI-enabled All-in-one Visual, Proximity, and Tactile Perception Multimodal Sensor</h2>
The sensors designed in this paper mainly include three modules: vision, proximity and tactile perception, among which the relevant perception and simulation codes of tactile perception are in this repositories. 

Visual Perception Reference：https://github.com/lyuwenyu/RT-DETR.git

Proximity perception reference：https://github.com/lyuwenyu/RT-DETR.git  

For tactile perception module:
1, Prepare your dataset and set your file path
2, Run ./algorithm/train.py

For simulation:
1, Get your Abaqus software ready
2, run ./simulation/abaqus-script.py
